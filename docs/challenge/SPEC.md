# Спецификация negacyclic-batched@1.0.0 (выжимка)

- Посчитать B независимых произведений c[j] = a[j]·b[j] в кольце Z_q[X]/(X^N+1).
- Точка рейтинга: **B=128, N=65536, W=1747**, L = ceil(W/32) = 55 слов u32 на коэффициент.
- q — наибольшее простое < 2^W с q ≡ 1 (mod 2N); одно на весь батч, выдаётся в setup.
- Раскладка a, b, c: `tensor<B x N x L x u32>`, B — внешнее измерение (пара j непрерывна), слова little-endian (как cuPQC BigInt). Вход и выход — в коэффициентной форме, не в NTT.
- c_{j,k} = (Σ_{i+i'=k} a_{j,i} b_{j,i'} − Σ_{i+i'=k+N} a_{j,i} b_{j,i'}) mod q, каждый коэффициент канонически в [0, q).
- Корректность точная, без допусков; батч верен, только если верно каждое произведение. Верификатора нет — сравнение побайтово с оракулом (digest).
- Пары независимы: любой порядок, группировка, чанки, перекрытие; батч можно прогонять через память GPU порциями.
- Всё, что зависит только от точки (N, q): константы Montgomery/Barrett, корни, твиддлы, буферы, потоки — готовится в setup, setup не замеряется.
- Данные: коэффициенты равномерно на [0, q), независимо для каждого многочлена; разреженных/малых/общих операндов нет.
- Объём: вход a+b = 3.69 ГБ, выход 1.84 ГБ.
